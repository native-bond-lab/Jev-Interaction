# Cookbook

这些做法来自我们产品里的语音通话引擎，已经在规模化的真实通话里运行。这里写的都是推荐做法：你不选，框架就不会用。

| 章节 | 讲什么 |
|---|---|
| [配置（Stacks）](stacks.md) | 大模型、语音识别、音色各接哪家；我们推荐的两套组合和理由；公开演示怎么限流 |
| [参数（Parameters）](parameters.md) | 通话的时间节奏：预设、四种节奏、每个 `Config` 字段，以及听到什么问题该调哪个 |
| [角色 policy（Role policies）](role-policies.md) | 角色在通话里怎么表现：怎么写给 Jev 读的 manner、怎么选策略、边听边说内容、转给另一个角色 |
| [示例角色](profiles) | 能互相转接的酒店前台和礼宾；你点一样就复述一样的面包店点单 |

## 三句话版本

- **配置**：四个节点（Jev、大模型、识别、音色）都由你选。我们推荐海外用 grok-4.3（关闭思考）+ ElevenLabs Scribe v3 Live + eleven_v4_turbo，中国大陆用一把百炼密钥（qwen-plus + Paraformer + CosyVoice）。模型字段不填就用服务商自己的默认值。
- **参数**：从 `recommended` 预设开始（我们产品在用的时间参数），只改你的产品需要的。先改角色的 manner，所有通话都有的问题再改参数。
- **角色 policy**：`prompt` 给大模型，决定说什么；`manner` 给 Jev，决定怎么说、什么时候说；`policies` 决定 Jev 的概率怎么变成动作。工作型角色用阈值，角色型的只抽小声音、开口前要 Jev 有把握。

标了「实验性」的功能已经在包里和演示页上，1.0 之前还可能改。
