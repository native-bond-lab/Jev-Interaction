# Cookbook

Recipes from the voice-call engine in our product, where they run at scale. Everything here is a recommendation: the
framework applies none of it unless you choose it.

| chapter | answers |
|---|---|
| [Stacks](stacks.md) | which language model, recognizer and voice to plug in; the setups we recommend and why; a public demo |
| [Parameters](parameters.md) | the timing of a call: presets, paces, every `Config` field, and which one to change for what you hear |
| [Role policies](role-policies.md) | a persona's behaviour on a call: writing the manner Jev reads, choosing policies, listening with content, handing over to someone else |
| [Example profiles](profiles) | a hotel front desk and concierge that hand over to each other; a bakery order line that says each item back |

Features marked *experimental* are in the package and on the demo, and may still change before 1.0.
